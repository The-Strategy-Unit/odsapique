# odsapique 📦🏥❔

An R package providing a few functions to help with querying the NHS
[ODS <dfn id="fhir"><abbr title="Fast Healthcare Interoperability Resources">FHIR</abbr></dfn> API][api],
also known as the Organisation Data Terminology <abbr title="Fast Healthcare Interoperability Resources">FHIR</abbr> R4 API

[api]: https://digital.nhs.uk/developer/api-catalogue/organisation-data-terminology


## Installation

```r
# install.packages("pak") # if not already installed
pak::pak("The-Strategy-Unit/odsapique")
```
